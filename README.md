# GeoFind AI

Puhelinystävällinen maailmanlaajuinen kuvanpaikannuksen MVP.

Render käynnistää palvelun Dockerfilella. Aseta Renderissä ympäristömuuttujat:
- OPENAI_API_KEY
- GOOGLE_MAPS_API_KEY
- OPENAI_MODEL=gpt-5
- MAX_CANDIDATES=8

Käyttö: avaa palvelun URL puhelimella -> ota/valitse kuva -> paina ETSI KOKO MAAILMASTA.
